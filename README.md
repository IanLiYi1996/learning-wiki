# Learning Wiki

用于持续记录、整理和复盘个人学习内容的私有知识库。

## 导航

- [收件箱](wiki/inbox/README.md)：暂未分类的想法、链接和速记
- [主题笔记](wiki/topics/README.md)：按知识领域整理的长期笔记
- [项目学习](wiki/projects/README.md)：围绕具体项目形成的实践记录
- [学习资源](wiki/resources/README.md)：书籍、课程、论文和工具
- [笔记模板](templates/learning-note.md)：新建学习笔记时使用

## 已整理的专题

- [Shader 与 Web 渲染](wiki/topics/rendering/README.md)：GPU 管线、WebGL、Three.js、PBR、性能调试与 WebGPU/TSL
- [Physical AI](wiki/topics/physical-ai/README.md)：业界产品与端到端方案、底层原理、学习路线、离线练习及 GTC 资料
- [大数据技术](wiki/topics/big-data/README.md)：技术分层、学习路线与 Palantir 研究

## 使用方式

1. 新内容先记入 `wiki/inbox/`。
2. 定期整理到 `topics/`、`projects/` 或 `resources/`。
3. 在笔记之间使用相对链接建立关联。
4. 每次学习结束后记录结论、问题和下一步行动。

## 文件命名

推荐使用小写英文和连字符，例如：

```text
transformer-attention.md
python-asyncio.md
```
