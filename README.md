## 使用方式

1. 新内容先记入 `wiki/inbox/`。
2. 定期整理到 `topics/`、`projects/` 或 `resources/`。
3. 在笔记之间使用相对链接建立关联。
4. 每次学习结束后记录结论、问题和下一步行动。

## 文件命名

推荐使用小写英文和连字符，例如：

```text
transformer-attention.md
python-asyncio.md
```
