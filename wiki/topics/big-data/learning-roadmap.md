# 大数据学习路线

## 阶段 1：基础能力

### 学习内容

- Linux、进程、线程、内存、磁盘和文件系统
- TCP/IP、RPC、序列化和数据压缩
- SQL、事务、索引和查询执行
- 分布式系统中的分区、复制、一致性、共识和容错
- 数据结构、复杂度与并行计算基础

### 完成标准

- 能解释吞吐、延迟、可用性和一致性之间的关系。
- 能分析一个查询主要消耗 CPU、内存、磁盘还是网络。
- 能说明分区和复制分别解决什么问题。

## 阶段 2：离线数据链路

### 学习内容

- 数据仓库分层与维度建模
- 行式与列式存储、压缩、分区和小文件问题
- 批量采集、分布式批处理和 SQL 查询
- DAG 调度、幂等、重试、补数和回填
- 数据质量检查

### 实践项目

构建一条每日离线链路：

```text
业务数据 -> 采集 -> 对象存储/数据湖 -> 批处理 -> 主题模型 -> BI 查询
```

要求记录数据量、运行时间、失败恢复方式和数据质量规则。

## 阶段 3：实时数据链路

### 学习内容

- 消息队列、发布订阅、分区和消费者组
- CDC、事件驱动和数据契约
- 流处理中的状态、事件时间、窗口、水位线和检查点
- At-most-once、At-least-once 与 Exactly-once
- 实时 OLAP 与在线数据服务

### 实践项目

构建一条实时指标链路：

```text
业务事件/CDC -> 消息平台 -> 流处理 -> 实时分析存储 -> 看板或 API
```

要求验证重复、乱序、延迟、任务重启和数据回放。

## 阶段 4：湖仓与统一数据平台

### 学习内容

- 对象存储与计算存储分离
- 开放表格式、快照、Schema 演进和时间旅行
- Catalog 与多引擎协作
- 批流一体的语义与现实边界
- Compaction、数据布局和查询优化

### 完成标准

- 能解释文件格式、表格式、Catalog 和计算引擎的边界。
- 能设计数据写入、更新、删除、回溯和并发读取方案。
- 能判断传统数仓、数据湖和湖仓分别适合什么场景。

## 阶段 5：治理与平台工程

### 学习内容

- 元数据、血缘、数据目录和数据所有权
- 数据质量、数据契约和变更管理
- 权限、脱敏、加密、审计和合规
- 指标、日志、追踪、SLA/SLO 和告警
- 资源调度、多租户、弹性和成本治理
- DataOps、基础设施即代码和自动化交付

### 实践项目

把前面的离线和实时链路改造成可运营的平台：

- 为数据集定义负责人和数据契约。
- 建立质量规则、血缘和告警。
- 记录资源使用和单位数据处理成本。
- 演练上游变更、任务失败和数据回滚。

## 阶段 6：专题深入

根据目标选择一到两个方向深入：

- 数据仓库与 OLAP
- 实时计算与事件驱动
- 数据湖与湖仓
- 搜索与日志分析
- 数据治理与 DataOps
- 大数据平台与云原生
- 面向机器学习的数据工程

每个方向都应形成“原理笔记 + 系统实践 + 性能实验 + 架构复盘”的闭环。

## 学习节奏

每周保持四类输出：

1. 一篇概念笔记。
2. 一篇技术笔记。
3. 一个可运行实验。
4. 一次本周问题与结论复盘。

判断是否真正掌握，不看记住了多少名词，而看能否：

- 解释原理。
- 画出数据流。
- 预测故障。
- 测量性能。
- 说明选型代价。
