# 术语速查：先分对象，再记英文

研究日期：2026-11-04。[返回专题](README.md)。定义为本专题的中文学习释义；正式机制与差异见各章和[来源表](sources.md)。

| 术语 | 本专题里的含义 | 最常见的混淆 |
| --- | --- | --- |
| Equity / Stock 股份 / 股票 | 公司所有权份额 | 股票代码相同就拥有股份 |
| Beneficial owner 实益持有人 | 经中介持有时的投资者权利身份 | 中介保管等于虚构股票 |
| Tokenized equity 股票代币 | 链上表示、但权利由发行结构定义的产品 | 一律等于直接股份或永续 |
| RWA 现实世界资产 | 现实资产相关的类别标签 | 标签本身证明储备与可追偿 |
| Derivative 衍生品 | 价值或支付依赖参考对象的合同 | 必须交付参考资产 |
| CFD 差价合约 | 以价格差结算的合同类别 | 所有产品都有相同清算机制 |
| Futures 期货 | 有约定结算 / 交付安排的合约 | 买入期货就是买入现货 |
| Perpetual 永续 | 通常没有预定到期日的衍生品 | 不到期就不能特殊结算或终止 |
| Synthetic exposure 合成敞口 | 取得类似价格风险，不自动取得底层资产权利 | 合成回报等于股东权利 |
| Underlying 标的 | 合约所参考的证券、指数或其他对象 | 简称唯一识别股份类别 |
| Multiplier 合约乘数 | 一个合约单位代表多少参考量 | 合约数量一定就是股数 |
| Long / Short 多头 / 空头 | 对参考价格上涨 / 下跌的仓位方向 | “买单”一定新开多头 |
| Notional 名义价值 | 数量乘规则对应价格和乘数 | 等于实际交付的保证金 |
| Margin 保证金 | 支撑仓位损失与风险要求的抵押 | 平台替你购买股票的资金 |
| Initial / Maintenance 初始 / 维持 | 开仓要求 / 持仓风险底线 | 维持保证金等于初始保证金 |
| Isolated / Cross 逐仓 / 全仓 | 限定分配 / 在适用范围共享的保证金模式 | Cross 一定跨全部币种和部署方 |
| PnL 盈亏 | 仓位价差损益，需区分毛值与净值 | 图上浮盈就是已可提取现金 |
| Funding 资金费 | 多空的周期性现金流 | 手续费、股息或固定利息的同义词 |
| Funding rate 资金费率 | 某明确周期的支付比例 | 小时率、8 小时率和年化可直接比较 |
| Basis 基差 | 本专题定义为合约价减股票价 | 等于固定可收取利润 |
| Basis points / bps 基点 | 1 bps=0.01 个百分点=0.0001 比例值 | 把 0.001% 读成 0.001 比例值 |
| Simple annualization 简单年化 | 恒定周期率按一年周期数展开 | 未来承诺收益或复利 APY |
| Oracle 预言机 | 提供并按规则更新的系统参考输入 | 从链外取得的任何数都正确 |
| Relayer 中继 | 将数据处理并提交到系统的角色 | 能提交数据就有股票储备 |
| External price 外部价格 | 来自所选外部市场 / 来源的价格 | 全球唯一公平价格 |
| Mark price 标记价格 | 用于估值、保证金和清算等的规则价格 | 一定可成交的价格 |
| Last price 最新成交价 | 最近实际发生的一笔成交 | 大额买卖都能按它成交 |
| Mid price 中间价 | 买卖最优报价之间的中间值 | 可执行报价或 Mark |
| Impact price 冲击价格 | 按规定名义金额模拟扫单得到的均价 | 最后一笔小额成交价 |
| Order book 订单簿 | 不同价位与数量的买卖委托 | 总有足够深度可以退出 |
| Spread / Slippage 点差 / 滑点 | 买卖价间距 / 实际成交与预期的差异 | 都是平台收取的固定费 |
| Liquidity 流动性 | 在给定规模和条件下可成交的能力 | 有成交量就可无限大额成交 |
| Liquidation 清算 / 强平 | 保证金条件不满足时的风险处置 | 亏完所有初始保证金才触发 |
| Backstop 后备接管 | 普通风险处置不足时的后备机制 | 全市场、所有部署方通用赔付保险 |
| ADL 自动减仓 | 尾部风险下减少对向仓位的机制 | 盈利仓位永远不受影响 |
| Reduce-only 只减仓 | 限制订单不增加相关敞口 | 保证仓位一定成功退出 |
| OI / Open interest 未平仓量 | 未平仓合约规模，口径要明确 | 股票流通股数或公司市值 |
| Discovery bounds 价格发现边界 | 特定时期对价格发现的控制 | 永久涨跌停或不清算承诺 |
| Corporate action 公司行动 | 分红、拆股、合并等证券事件 | 合约必然按券商相同方式处理 |
| Ex-dividend 除息 | 股息权利与交易价格相关的事件节点 | 价格跌幅就是持股总回报损失 |
| ATS 另类交易系统 | 正常交易所之外的一类证券交易场所 | 任何人都有相同隔夜权限与深度 |
| HIP-3 / Deployer 部署方 | Hyperliquid 的第三方永续市场部署机制 / 主体 | Hyperliquid 官方统一保证各部署规则 |
| Slashing 罚没 | 规则下对质押的处罚 | 自动赔给损失用户的保险 |
| USDC settlement USDC 结算 | 资产和盈亏以 USDC 处理 | 与美元法币永远等价 |

## 三组单位必须分开

1. **数量、名义价值、保证金**：100 单位 × 100 参考价=10,000 名义价值；1,000 保证金不使名义价值变成 1,000。
2. **百分号、基点、比例值**：0.001%=0.1 bps=0.00001；0.01%=1 bps=0.0001。
3. **时间口径、年化、保证金收益**：某小时费率 × 8 不是“下一段 8 小时必定如此”；年化只是给定假设下的比较表达。

这些是数学约定。实际产品参数必须查版本与正式规格，不应从术语表反推当前费率或风控阈值。
