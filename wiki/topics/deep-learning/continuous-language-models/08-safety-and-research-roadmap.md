# 08 安全与研究路线：联合生成提供接口，不提供保证

核查日期：2026-11-11。[专题导读](README.md) · [综述边界与来源](sources.md#survey)。

## 1. 连续状态不直接是可读文字

连续轨迹中包含向量、soft predictions 或 latents。将它们每一步 readout 成暂定文字，可能帮助检查，却不证明那是模型的忠实解释，也不证明能看到所有危险表征。

少步一次生成大量内容，会改变可检查／可中断的机会。安全设计应重新评估监测、最终检查、外部行动门槛和回滚，不直接照搬逐 token 输出时的监控假设。

这些是研究与工程建议；没有证据表明所有连续模型都更危险或更安全。综述 §8.5 将可解释、监测和约束连续轨迹列为开放方向，而不是完成的产品保证。[作者综述](https://www.alphaxiv.org/abs/2611.continuous-diffusion-flow-language-models.pdf)

## 2. 三类误差不能混为一个“模型不够好”

| 误差 | 原创定位问题 |
| --- | --- |
| 表示／解码误差 | 正确连续目标能否恢复文字？生成扰动是否越过决策边界？ |
| 学习误差 | 条件均值、速度或 map 是否学对了？是否有 collapse？ |
| 推理近似误差 | 少步积分、缓存、提交、guidance 是否改变目标过程？ |

若只改 sampler 后成绩提高，不能自动归因于表示更好；若继承更强的 AR 权重，也不能把全部提升归给连续状态。每一项需要保持其他因素可比。

## 3. 后训练还有接口缺口

SFT 可以沿用适当的连续目标，但许多 RL 方法依赖便宜的动作 likelihood。连续轨迹的 density、离散 decoder 的 marginal、随机转移 likelihood 与可微 reward 不是一个对象。

研究方案应写清优化哪个分布、哪些动作被采样、如何取得概率或梯度，以及评分器偏差。不能把“梯度能穿过表示”当作奖励真实、行动合法或最终质量保持的证明。

## 4. 多模态统一，先对齐不同难度和预算

将文字、音频与图像放进连续表示，使联合过程成为可能，但不同模态的 token 可辨识时间、尺度、decoder 和成本并不相同。

建议在同步、语义与每模态质量上分别评价；报告各模态采样与解码预算。共享数学名词 flow，不证明模型直接继承了[实时双工交互](../realtime-interaction/README.md)的时间控制或工具状态管理。

## 5. 六个可执行的研究问题

1. 表示冻结与联合学习：同初始化、同预算，重构与生成如何同时变化？
2. 噪声调度：固定目标时，只改变估计方差的效应有多大？
3. 少步目标：semigroup 与对角项怎样平衡，哪些任务发生 mode collapse？
4. 推理策略：guidance、内迭代与提交是否改善同等总调用预算的质量？
5. 评价：匹配质量／多样性后，实际时延是否仍有优势？
6. 安全：中间 previews 能发现什么、漏掉什么，误报／漏报如何统计？

这是本 Wiki 的研究清单，不是已完成实验。先用小合成任务、固定验证器和预算找接口错误，再决定是否申请真实模型与算力。
