# 04 训练调度与反馈：哪些状态被看见，哪些误差被优化

核查日期：2026-11-11。[专题导读](README.md) · [原始方法与版本](sources.md)。

## 1. 均匀抽 t，不一定均匀覆盖学习难度

某些时间段几乎纯噪声，另一些几乎没有不确定性；token 可辨识性可能在很窄的区间迅速变化。均匀时间网格并不保证把训练和推理预算放在最有用的地方。

CDCD 使用 time warping；FLM 研究 one-hot 在噪声下的可恢复性并调整时间坐标；Plaid／RePlaid 则研究 likelihood 目标及估计方差。名称都是 schedule，目标却不相同。[CDCD](https://arxiv.org/abs/2211.15089v3) · [FLM](https://arxiv.org/html/2602.16813v3) · [RePlaid](https://arxiv.org/abs/2605.18530v3)

## 2. 路径、抽样、权重、推理网格是四个选择

| 选择 | 改变什么 |
| --- | --- |
| Corruption path | 每个 t 对应怎样的状态分布 |
| Training time distribution | 学习时常见哪些噪声等级 |
| Loss weight | 各状态的误差贡献有多大 |
| Sampling grid | 生成时在哪些位置花模型调用 |

原创直觉：若从一个偏向困难区间的分布抽样，又直接沿用旧权重，可能改变优化目标。若只想改变估计方差，需要正确的权重补偿及支持集条件；不能把“更多看困难样本”自动称为同一个目标。

推理使用更密的局部网格，可以改变积分误差，但不替代训练 coverage。所有配置应保存版本，避免把模型变化和 sampler 变化混为一谈。

## 3. Self-conditioning 反馈的是什么？

一种接口是：

$$
\widehat x_1=D_\theta(x_t,t,z),
$$

其中 z 可为上一轮预测的干净表示、token 概率或隐特征。它允许模型从已有估计继续细化，不必每次从无反馈开始。

训练与推理会不同：部分方法训练时用无梯度的预预测，推理时用上一步已有预测。具体输入、刷新与 stop-gradient 应逐方法检查；不要把一种半数样本规则当成所有模型的统一做法。[CDCD](https://arxiv.org/abs/2211.15089v3) · [ELF](https://arxiv.org/abs/2605.10938v3)

它通常属于一次生成内的状态，不是[跨会话 Agent memory](../../agent-memory/01-memory-and-state.md)，也不意味着网络权重在每次推理时更新。

## 4. 固定 x 与 t 的迭代，不是前进采样时间

原创小迭代：

$$
z_{j+1}=(1-\eta)z_j+\eta F(x_t,t,z_j).
$$

j 是内部反馈次数，t 是 flow 时间。保持 x_t、t 不变，可以继续改 z；推进 t，则改变生成状态。两类计算都可能增加模型调用，不能只数 t 网格里的步数。

反馈也可能强化错误和重复。自信越来越高不等于越来越对；重复 pattern 的修正与真实任务评价仍必要。

## 5. 一个 flow map 为什么不能忘掉 z？

若下一速度依赖先前预测 z，状态 x 本身不再闭合。学习只输入 x、s、t 的 map 时，要么将反馈并入状态，要么给出有依据的 closure／蒸馏方式；否则同一 x 可以因不同历史 z 走向不同输出。

这是接口一致性问题，不是说 self-conditioning 不可用于少步模型。后文的少步映射需要明确处理训练和推理的反馈合同。[综述 §5.5 的讨论](sources.md#survey)

## 6. Loss 降了，先确认学对了对象

表示坍缩可以降低 MSE，缩放可以改变噪声难度，某种 schedule 可以让估计更稳定。都需要配合重构、任务和分布评价。

建议记录网络实际预测什么、loss mask／权重、词表与表示版本、时间采样、反馈来源、所有额外前向，以及持出质量。不用一个平均训练 loss 给所有机制排胜负。
