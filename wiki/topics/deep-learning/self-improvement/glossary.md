# 自我改进术语：缩写先对应到对象

资料核验截止：2026-10-17。Wiki 整理日期：2026-11-04。[返回专题](README.md)。

同一个“自改进”标签可能指一次回答、一个程序或一套训练过程。先确定对象，再看术语，会比逐个记项目缩写更有用。下面是本专题的阅读用语，不替代每篇论文自己的定义。

## 系统与状态

| 术语 | 白话含义 | 不要直接推出什么 |
| --- | --- | --- |
| RSI | 新版本参与下一轮自身改进 | 不自动意味着无限或加速增长 |
| Agent／智能体 | 模型加上工具、记忆、控制程序等任务执行系统 | 不是只有一组神经网络权重 |
| Harness／scaffold | 安排上下文、工具、执行和恢复的外围程序 | 它变好不表示基础模型参数也变了 |
| Task agent | 实际执行任务的程序 | 解题更好不等于更会改进别人 |
| Meta agent／改进器 | 产生、组织或评价系统修改的方法 | 名字有 meta 不保证它也在学习 |
| Archive／档案 | 保存候选版本和历史的集合 | 分支更多不自动产生有用新能力 |
| State／状态 | 权重、代码、记忆、工具与正在执行的信息 | 状态变化不等于能力提升 |

## 学习和搜索

**内层与外层**描述相对位置。SEAL 的内层是适应参数，外层学习生成学习材料；研究 agent 的内层可以解研发任务，外层改研究流程。应分别记录两层的固定项和更新项。

**Meta-learning／元学习**学习如何更快适应。MAML 学习便于少步更新的起点，RL² 在记忆状态里形成适应行为；外层仍可以是人工固定算法。[基础参照](concepts-and-foundations.md#rsi-meta-learning)

**On-policy／当前策略采样**指用正在学习的模型产生轨迹，而不是只训练在一份旧模型固定样本上。它不等于没有监督或验证信号。[SCoRe](learning-and-weights.md#rsi-score)

**Self-edit**是 SEAL 生成的适应材料或配置，不保证每次都改出正确知识。[内外循环](learning-and-weights.md#rsi-seal)

**Open-ended／开放式探索**允许继续产生和保存多种候选；它描述搜索方式，不是无限进步定理。

## 反馈、预算与证据

| 术语 | 应怎样读 |
| --- | --- |
| Oracle／验证器 | 实现的检查机制，不是全知真值；它有范围和错误 |
| Proxy reward／代理奖励 | 可以被优化的指标；要另看真实目标是否改善 |
| Held-out／留出 | 未用于相应训练或选择；若不断反馈，就不再独立 |
| Best-of-N | N 次中挑好结果；机会变多不等于生成方法学习了 |
| pass@k | k 次中至少成功一次的统计；不是 k 轮自修改 |
| imp@k | 给改进器 k 次产生候选的机会，检查后代测试增益；还要算每次成本 |
| Ignition test | 检查改进后的系统是否更会推动后续改进；不是“点火”宣传词 |
| Pareto 曲线 | 同时比较能力、成本或延迟，不用一个分数掩盖代价 |
| 归一化分数 | 相对指定起点／参考的量尺，不是通用智能倍数 |

美元、token、GPU 时间和墙钟时间不能完全互换。固定一次训练时长，不表示编译、验证、失败候选和外层推理都免费。[评测合同](evaluation-and-safety.md)

## 常见误读

“Zero Data”要问零的是哪类数据。AZR 不需要人工训练示例，却仍有预训练模型和执行器；R1-Zero 不先做 SFT，也不从空白网络开始。[学习与权重](learning-and-weights.md)

“自主发现”要看人在哪里。科学家设置目标、做实验、预处理数据、筛选候选和投稿，可以同时存在于一个有价值的自动工作流里。[科学家系统](ai-scientists.md)

“High capability”是开发者风险框架的特定门槛。它不与本专题 RSI 的操作性问题完全等同，也不能替代多代因果实验。[工业研发](industry-and-autoresearch.md)

“Open”要分别核对代码、权重、数据、服务与许可。公开作图脚本不等于核心系统全部可离线运行。[来源边界](sources.md)
