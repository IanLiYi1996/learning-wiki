# 权重空间编程术语：把参数、运行与证据分开

这些是本专题的教学释义。机制与出处见[图文解读](weight-space-programming.md)，实验条件见[一手来源](weight-space-programming-sources.md)。

## 计算对象

| 名词 | 白话解释 | 最容易混淆 |
| --- | --- | --- |
| Architecture／架构 | 哪些计算部件按什么顺序连接 | 不等于已知具体计算功能 |
| Weight／权重 | 网络中保存的可调整数值 | 一个大数字不自动代表一个概念 |
| Parameter／参数 | 包括权重、偏置等可参数化对象 | 数参数时只数矩阵会漏偏置 |
| Tensor／张量 | 带形状的数值数组 | Flatten 后的数字仍需要布局信息 |
| Checkpoint | 模型某个版本的参数及相关保存状态 | 不必天然包含全部输入语义或推理配置 |
| Activation／激活 | 某次输入产生的中间数值 | 不是静态权重 |
| ReLU | 逐元素取 `max(0,x)` | 不能与任意旋转交换顺序 |
| Logit | 归一化之前的输出打分 | 不是概率，也不天然是最终动作 |
| Forward Pass／前向 | 给定输入，执行网络得到结果 | 不等于反向传播或训练 |
| Gradient／梯度 | 损失对参数的局部变化率 | 不等于任何形式的反馈 |
| Optimizer／优化器 | 根据规则提出参数更新 | 用 LLM 改优化器代码不自动属于直接权重编程 |

## 机制与方法

| 名词 | 白话解释 | 最容易混淆 |
| --- | --- | --- |
| Weight Space | 由参数坐标组成的空间 | 参数距离不直接等于行为距离 |
| WSP | 本篇所讨论的通用 LLM 读取或构造目标网络参数 | 不等于目标网络从未训练 |
| Hypernetwork | 生成另一个网络权重的专门网络 | 原始方法的生成器也需训练 |
| Neural Compiler | 把某种受约束程序编译成网络 | 不保证任意自然语言规格都可编译 |
| Model Editing | 修改模型，使某些行为或知识改变 | 需同时检查局部有效性和非目标影响 |
| Residual Stream／残差流 | Transformer 中各模块读写的表示通道 | 不是一条可直接读懂的自然语言文本 |
| QK Circuit | 查询与键共同决定表示匹配的计算 | 只看静态矩阵未得到真实输入的完整注意力 |
| OV Circuit | 值与输出映射共同决定读来的内容怎样写出 | 与“看哪里”是不同问题 |
| Induction Head／归纳头 | 利用序列重复关系延续模式的注意力机制 | 不能仅凭一句合理解释就宣布定位成功 |
| Direction／方向 | 表示空间中指定的向量或轴 | 不自动对应独立、单一的行为 |
| Rank-One／秩一 | 矩阵变化可表示为两个向量的外积 | 低秩不等于影响很小 |
| Projection／投影 | 分解并保留或去掉某方向分量 | 处理部分列不等于处理整个矩阵 |
| Permutation／置换 | 重排坐标或隐藏单元的顺序 | 必须同步调整相邻层连接 |

## 研究与工程证据

| 名词 | 白话解释 | 最容易混淆 |
| --- | --- | --- |
| Mechanistic Interpretability | 试图解释网络内部具体计算机制 | 与“模型会自己讲理由”不同 |
| Causal Intervention／因果干预 | 修改特定部件，检验预测的效果 | 相关性图案不等于因果机制 |
| Ablation／消融 | 移除或改变部件来检验其作用 | 任意破坏模型不保证定位了唯一原因 |
| Harness | 工具、权限、记录和评测的外围执行系统 | 不只是一个提示词 |
| Zero-shot／零样本 | 要按实验定义看是否没有目标任务示例或适配 | 规则、源码、预训练先验仍可能存在 |
| Gradient-free／无梯度 | 不使用目标梯度进行更新 | 可以有前向反馈或黑盒选择 |
| Baseline／基线 | 作为比较的固定方案 | 权限、预算不同可能改变比较意义 |
| Validation／验证集 | 用于选择或调整方案的评测输入 | 不能冒充从未用于选择的测试集 |
| Regression／回归检查 | 观察原来正确或非目标行为是否受损 | 总分上涨不代表每个功能都安全 |
| Independent Replication | 由独立过程重建并核验结果 | 发布日志、模型重建和本地玩具测试不自动等于它 |

不必先背完缩写。遇到任何醒目的结果，先问：**修改谁、看到了什么、允许什么、按什么计分、还有什么没验证？**
