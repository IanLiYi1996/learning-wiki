# 04 评测记忆：任务收益、错误与全部成本一起算

核查日期：2026-11-11。[专题导读](README.md) · [原文实验协议](sources.md#evaluation)。

## 1. 不把不同指标叫作同一个“准确率”

| 指标 | 回答什么 | 不能自动代表什么 |
| --- | --- | --- |
| 检索 recall／precision | 参考信息是否找到、候选是否相关 | 是否适用、是否正确执行 |
| Reward／任务得分 | 指定评分规则下做得怎样 | 每题是否全对 |
| Criteria coverage | 满足多少细项标准 | 整个任务全部通过 |
| All-pass／精确任务成功 | 本题所有必要条件是否满足 | 完成花了多少资源 |
| 更新／遗忘测试 | 旧事实是否失效，删除是否传播 | 所有备份和服务都已清除 |
| Token／时延／成本 | 资源与服务表现 | 内容真实或权限合法 |

CL-Bench Database Exploration 可同时奖励答对与节省探索；LAB 的当前官方计分与原文的选定细项覆盖又不相同。不能把 30 题数据库单项、40 题默认漂移协议、某一个合同案例混成统一总分。[官方协议与版本](sources.md#evaluation)

## 2. 先锁定比较中的不变量

至少固定模型、任务顺序、工具与权限、历史起点、反馈、预算、停止规则和评分器。记忆方法往往会同时改变召回量、额外推理、在线工具调用和维护计算。

原创对照设计：

| 条件 | 想分离的因素 |
| --- | --- |
| 不跨会话保留信息 | 无记忆起点 |
| 原始日志搜索 | 能访问历史的价值 |
| 笔记／wiki＋搜索 | 表示组织在检索上的增量 |
| 可读但禁止写 | 已有记忆与自主积累分别贡献什么 |
| 禁止 dreaming | 维护计算的增量 |
| 等总预算替代方案 | 效果是否主要来自更多计算 |
| 版本／事实漂移 | 原来成功的经验是否仍适用 |

这是验收建议，不是 Anthropic 已完成的全因子消融。原文若捆绑改变 prompt、写入所有权和引用方式，就不能把全部收益只归给其中一个因素。

## 3. 状态重置与自由运行测到不同对象

令当前任务得分为 $Y$，记忆为 $M$，起点为 $S$。固定参考起点的比较可记为：

$$
\Delta_{\rm fixed}=E[Y(M,S^{ref})-Y(\varnothing,S^{ref})].
$$

自由运行中的 $M$ 和 $S$ 都可能受到此前错误影响，长期累计收益不是这个单步差。随机重置可帮助隔离组件效应，却可能切断错误积累；完全自由运行更接近服务体验，却增加归因难度。

这是一种实验分解，不是本次算出了真实效应。相关参考历史与 checkpoint 的边界见[已有执行评测专题](../deep-learning/openmoss/06-agent-memory-and-executable-evaluation.md)。

## 4. 正确答案反馈不是泄漏许可

在指定学习协议中，答后反馈可以成为下一题的经验；但开发失败用于优化构建 prompt 后，不能再把相同题目称为从未见过的最终测试。

建议分开经验形成任务、开发选择集与持出测试；记录哪些题目、答案和 rubric 曾进入笔记、wiki 构建或 dreaming 指令。数据可见性本身就是实验条件。

不同模型各玩一次游戏、存储文件数不同，并不是对记忆结构的单因素随机实验。应避免把案例进度差改写成“更少文件使能力提升四倍”。

## 5. 在线省 token，何时才回本？

原创计算：构建成本 120 个预算单位，每次普通查询成本 10；有记忆后在线成本 7，更新摊销每次 1。每题净省 $10-(7+1)=2$，相等点是 **60 题**。

$$
C_{\rm memory}(N)=C_{\rm build}+C_{\rm update}(N)+N C_{\rm online},
\qquad
C_{\rm baseline}(N)=N C_{\rm base}.
$$

若更新／查询总开销不低于 baseline，就没有这个线性模型中的有限回本点。单位是假想值，不是 API 美元价格；真实服务还可能有读取、缓存、存储、失败重试、维护延迟与流量波动。

Sleep-time Compute 的成本模型也依赖复用次数与在线／离线单位价格，不能把其某个倍数推广为所有记忆服务的账单收益。[成本来源与假设](sources.md#cost)

## 一页验收合同

记录任务与版本、历史构造、跨题反馈、权限、读写／维护预算、模型／采样、评分器、失败分母、重复次数、统计区间，以及数据更新与删除的测试。把速度、质量和风险分别报告，不让成本节约遮住错误传播。
